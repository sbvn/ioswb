# IOS-003 运行现有程序一次：打开微博、首页刷新一次、随机滑动

## 元数据

- 任务 ID：IOS-003
- 标题：运行现有程序一次（打开微博 → 首页刷新 1 次 → 随机滑动 3–6 下）
- 版本：v1 / r1
- 状态：已发布（01）
- 发布日期（Asia/Hong_Kong）：2026-11-17
- 分档：**人工档**。本任务碰手机与真实触摸，永不自动执行；
  不进 `manifest/releases.json`，等待器不会领取。执行方式只有
  `automation/IOS-003-RUN-ONCE.md` 的一次交接，用户在场。
- 业务目录：`D:\GoDemo\wbjiaoben`
- 设备：仅 `DEVICE_A`（单机）

## 背景与目标

用户 2026-11-17 明确要求：用现有代码中的程序打开微博，首页刷新一次，
然后模拟人工滑动几下（随机）。本任务只运行现有程序一次，不开发新功能、
不改业务代码。

程序基线（来自 IOS-001 回执的源码静态核对，执行前必须复核现行源码）：

- 入口：`weibo_browse.py`，扁平参数包括 `--device`、`--bundle`、`--open`、
  `--run`、`--confirm-home`、`--output-dir`、`--seed`、`--refresh-min`、
  `--refresh-max`、`--swipe-min`、`--swipe-max`。
- `--open` 会 spawn 并 resume 微博；只有 `--run --confirm-home` 进入
  真实触摸流程；不带 `--run` 的默认路径只 attach + 诊断，不得拿它冒充执行。
- 真实触摸的证据标准：运行记录里 `touch_kind=real_iohid_touch`。
  程序化滚动（`programmatic_uikit_setContentOffset`、`touch_gesture=false`）
  不算完成。

## 执行命令（本机复核参数后执行一次）

```text
python weibo_browse.py --device <DEVICE_A 在本机的既有参数> --bundle <现行源码默认或既有值> --open --run --confirm-home --refresh-min 1 --refresh-max 1 --swipe-min 3 --swipe-max 6
```

- `--output-dir`、`--seed`：用程序默认（不传）。不设 seed，滑动次数在
  3–6 内由程序随机；实际次数以运行记录为准、写进回执。
- 参数与现行源码对不上（改名、缺失、语义变化）：停，不要猜、不要改代码，
  把现行参数清单写进回执交回 01。
- 只跑一次、只跑一轮。不用 `weibo_batch.py`，不开批次。

## 执行前只读动作（允许）

1. 读现行 `weibo_browse.py` 的参数定义，核对上表。
2. 计算并记录三个文件的 SHA256（只读，不改）：
   `weibo_browse.py`、`weibo_browse_agent.js`、`weibo_touch_agent.js`。
   业务目录无 Git，这组哈希就是本轮的版本证据（IOS-001 验收的既有要求）。
3. 确认设备连接、微博可启动、当前没有同一程序的另一实例在跑。

## 允许与禁止

允许：按上条命令 spawn 微博一次；程序既有流程内的首页刷新 1 次与
真实触摸滑动 3–6 下；程序自己既有的启动干扰处理（仅限程序已实现、
已记录在案的动作）；把脱敏回执 push 到 `results/IOS-003/r1/a1.md`。

禁止：

- 改任何业务代码、配置或识别规则；跑失败就如实报告，不许边跑边修。
- 登录、注册、输入任何凭据；遇到登录墙或未登录导致进不了首页：
  停在该状态、记录、结束本轮，不做任何登录动作。
- 点赞、关注、评论、转发、发帖、私信等一切互动动作；打开任何帖子详情
  之外的页面（滑动浏览首页本身除外）。
- 程序化滚动冒充真实触摸；截图、录屏上传仓库（画面证据只留本机，
  回执只写相对路径与摘要）。
- 第二轮、第二台设备、改参数重跑；`pause_for_user` 要求人工介入时
  停下来等用户决定，不绕过。

## 停止条件（任一触发即停，保存本机证据后写回执）

- Weibo agent lost / `infrastructure_agent_lost` / `process-terminated`；
- 程序非 0 退出，或触摸证据不是 `real_iohid_touch`；
- 首页不可达（登录墙、闪退、长时间无响应）；
- 出现程序未覆盖的新弹窗或页面，且继续需要计划外点击；
- 用户喊停。

## 回执（results/IOS-003/r1/a1.md）

必须包含：实际命令（设备写别名、脱敏）、三个脚本的 SHA256、程序退出码、
实际刷新次数、实际滑动次数、`touch_kind` 原文、关键时间线
（spawn、attach、首次成功 RPC、detach 原因、进程是否存活、清理顺序）、
输出目录的相对路径、触发的停止条件（如有）、未验证项。
结论只能从运行记录得出：刷新与滑动是否完成，分别标注证据来源。
