## 1. 停止原因（只读复核结论）

任务单要求执行的命令是：

```text
python weibo_browse.py --device <既有值> --bundle <既有值> --open --run --confirm-home \
  --refresh-min 1 --refresh-max 1 --swipe-min 3 --swipe-max 6
```

现行 `weibo_browse.py` 的参数名与任务单基线**全部对得上**（11 个），但**取值范围不一致**：

| 项 | 任务单 | 现行源码 |
| --- | --- | --- |
| 参数名 | 11 个（device/bundle/open/run/confirm-home/output-dir/seed/refresh-min/refresh-max/swipe-min/swipe-max） | **全部存在**，无改名、无缺失 |
| refresh 范围 | 1 / 1 | `1 <= min <= max <= 3`（L162-L163），**1/1 合法** |
| swipe 范围 | 3 / **6** | `2 <= min <= max <= **5**`（L164-L165），**6 超上限** |

- `validate_args()` 在 `--swipe-max 6` 时走 `fail("--swipe-min/--swipe-max 必须满足 2 <= min <= max <= 5。")`，
  而 `fail()` 会 `raise SystemExit(1)`（L68-L70），**在任何设备连接之前**就退出。
- 程序自己的 `--swipe-max` 帮助文本也写「2–5」（L152-L153）；默认值 `SWIPE_MAX_DEFAULT = 5`（L46）。

即：任务单想要的「随机滑动 3–6 下」用现行程序表达不出来。按任务单「参数与现行源码对不上：停，不要猜、不要改代码，把现行参数清单写进回执交回 01」，本轮停止。

没有把 `--swipe-max` 改成 5 去「凑合跑」——那属于猜参数；也没有改代码放宽校验——那被本单禁止。
